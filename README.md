# Laser Sentry Cooldown

Laser Sentry Cooldown now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Laser Sentry Cooldown's C source is in
[`src/components/laser_sentry_cooldown`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/laser_sentry_cooldown).

The standalone Lua mod (v1.1.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/LaserSentryCooldown/tree/legacy) branch. Its releases and tags are unchanged.
